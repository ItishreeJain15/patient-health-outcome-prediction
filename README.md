# 🩺 Patient Health Outcome Prediction System

An AI-powered healthcare prediction web app built using Machine Learning and Streamlit. The system analyzes patient symptoms and medical information to predict possible health outcomes.

## 🚀 Technologies Used:- Python, Pandas, Scikit-learn, Streamlit, Random Forest Classifier

## 📊 Features
- Health outcome prediction
- Interactive healthcare UI
- Machine learning-based analysis
- Real-time predictions
